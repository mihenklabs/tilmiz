# Tilmiz

Türkçe konuşanlar için ücretsiz, reklamsız Arapça öğrenme uygulaması: aralıklı tekrarla 11.719 kelime, dil bilgisi dersleri, fiil çekimi, ayet ve hadisler kelime kelime, günlük diyaloglar.

## Geliştirme
```
npm install
npm test        # derler (dist/) ve testleri çalıştırır
npm run build   # yalnızca derler
```
- `dist/elifba-kelime.html`: tek dosyalık sürüm
- `dist/site/`: PWA (GitHub Pages / Google Play TWA)
